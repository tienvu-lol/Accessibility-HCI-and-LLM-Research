# CORP-05 fidelity notes

## Replicated information architecture

Home → everyday banking → checking; rates; member support → contact; locations; about. The source’s personal-banking, membership, sign-in, support and locations paths inform repeated navigation. Home follows financial well-being → products → learning → community/help bands. Checking follows benefits → rate context → eligibility/opening explanation → FAQ. Rates groups deposits, mortgages/home equity, vehicles and other personal/business products. Contact groups phone, messaging, video, hours/mailing, security and suggestion/media topics. Locations has directory and planning content. About centers member ownership and impact.

## Approximated

Original serif-led editorial headings, burgundy CTAs, cream/sage content bands and a compact utility header approximate a credit-union marketing hierarchy. Exact rendering, source spacing, imagery, color values, breakpoint and responsive order were unavailable in HTTP research. No pixel fidelity claim. Native details approximate source expanded/disclosure clues; compact mobile disclosure approximates navigation states. Source tab markup was observed but individual tab relationships were not verified; direct local navigation is used instead of inventing audience-tab panels.

## Simulated and inferred

Sign-in opens a notice with no credential fields. Membership/opening is explanatory only. Local directory filtering across three invented branches is an inferred approximation to “find nearby locations”; no source input fields were returned. No live map, route, geolocation or appointments. All contact channels are descriptions, not callable links/submission controls.

## Intentionally added

Native dialog notice provides an honest endpoint to the observed sign-in affordance. 404 is the protocol-required recovery page. Research banners and explicit simulation notes prevent confusion.

## Omitted

Numeric rate tables (not observed), real trademarks, copied media/prose, real member data, real credentials, financial transactions, applications, membership eligibility decisions, contact inquiry form (not observed), calculators (not inspected), careers (not mapped), external messaging/video/maps and speculative screens. No unsupported audience/business product screens.

## Unverified

Rendered source layout, interactions, mobile menu, exact tab behavior, location widget, account-opening process, contact submissions, current financial rates and full eligibility geography. Static implementation checks and JS tests cannot substitute for browser/assistive technology review. Detailed test outcomes are retained with the run.
