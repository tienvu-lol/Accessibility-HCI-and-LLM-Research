## Feature checklist
- Fictional-publication note in the masthead of every page including 404.
- Flat primary nav, aria-current, mobile disclosure button (aria-expanded, Escape closes). No dropdowns (none observed).
- Header search and search page over inline data, with empty and blank-query states.
- Keyword/topic/section/sort filters with live count and empty state (section pages, Latest).
- Article gallery: Previous/Next, thumbnails, polite "Slide n of 6", arrow keys, no autoplay, lightbox dialog with Escape and focus return.
- Newsletter simulation: required email and delivery day, inline errors, error summary with focus and field links, simulated success that says nothing is stored or sent.
- Reduced motion: no autoplay anywhere; CSS removes animations and transitions under `prefers-reduced-motion`.
- Skip link, landmarks, one h1 per page, `data-section`/`data-component` metadata.

## Interaction simulation notes
