Accessibility statement

How this demo was built, and what is not yet known.

What this site aims for

This is a research replica built against WCAG 2.2 level AA as an implementation target. We have run automated checks and scripted keyboard tests; we have not carried out an audit, so we make no claim of conformance.

  • Skip link, landmarks and a logical heading order on every page.
  • Keyboard operation of menus, filters, the gallery and the enlarged image view; Escape closes menus and the enlarged view.
  • Text alternatives for every image, and decorative images marked as such.
  • Colour names written out beside every swatch.
  • Reduced-motion support, and no autoplay anywhere.

Known limits

No testing has been done with assistive technology such as screen readers or voice control. The company, its stockists and all dates are invented. Feedback about this demo can be sent through the simulated contact form, which does not deliver messages.
