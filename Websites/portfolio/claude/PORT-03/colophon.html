Colophon

How a motion studio's site gets built without a single video file.

The stack

Everything this site runs on
MarkupHand-written HTML5, 19 pages, each complete on its own.
StylesOne stylesheet. Light palette first, with a dark palette under prefers-color-scheme.
ScriptOne file: site data, then small named features pushed onto a registry. A failing feature is caught and logged rather than taking the page down.
ComponentsBootstrap 5.3.3 for the grid helpers, dropdown and off-canvas menu, stored locally.
jQuery3.7.1, stored locally, loaded on every page for tooling. This site's own code never calls it.
SlideshowHand-written, so that it never autoplays, always has a pause control, and announces each slide.
MotionCSS animations on inline SVG marks, which is what lets one header control pause every loop at once. An animated file in an <img> could not be paused that way.
Images18 labelled SVG placeholders. No raster files, no video, no web fonts.
Build stepNone. The file edited is the file the browser gets.

Annotation

Every layout region carries data-section and every repeated or interactive component carries data-component, so any part of a page can be addressed by a stable selector such as [data-component="motion-toggle"]. The full list is in component-inventory.json.

Deliberately missing

  • Video. A studio site would carry it; a research replica that must run offline from a folder cannot ship a reel, so the player is a labelled demo.
  • Analytics, cookies and third-party scripts of any kind.
  • A theme toggle: this site follows the operating system only, which is a deliberate difference from PORT-02 in the same set.

Credits

Bootstrap and jQuery are MIT licensed; their licences sit beside them in assets/vendor/. Everything else was written for this replica.
