Colophon

How this site is built, and the budget it is held to.

The stack

Everything this site runs on
MarkupHand-written HTML5, 19 pages, each complete on its own.
StylesOne stylesheet. Dark palette first, light palette for prefers-color-scheme: light and for the explicit toggle.
ScriptOne file: site data, then a module of named init functions. No modules, no transpiler.
ComponentsBootstrap 5.3.3 for the grid, dropdown and off-canvas menu, stored locally.
jQuery3.7.1, stored locally, loaded on every page for tooling. This site's own code never calls it.
LightboxThe native <dialog> element, not a library.
ThemeStored in localStorage and applied before first paint by a four-line inline script, so the page never flashes the wrong palette.
Images13 labelled SVG placeholders. No raster files, no web fonts.
Build stepNone. The file I edit is the file the browser gets.

Annotation

Every layout region carries data-section and every repeated or interactive component carries data-component, so any part of a page can be addressed by a stable selector such as [data-component="archive-table"]. The full list is in component-inventory.json.

Deliberately missing

  • Analytics, cookies and third-party scripts of any kind.
  • A content management system: the content is the files.
  • Web fonts. The type is whatever your system already has, which is faster and more legible than most of what I would have chosen.

Credits
