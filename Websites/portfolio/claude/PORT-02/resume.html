Experience

  1. 2024 — present

    Senior frontend engineer, accessibility

    Keelpoint · Boston

    • Own the component library used by six product teams: 74 components, one keyboard model, one focus specification.
    • Cut time to interactive on the scheduling view from 3.1s to 0.9s, mostly by removing code.
    • Run the accessibility programme: WCAG 2.2 AA baseline on new screens, automated checks in review, quarterly manual passes.
    • Mentor four engineers and run a fortnightly “break the interface” session.
  2. 2021 — 2024

    Frontend engineer

    Tidemark · Remote

    • Rebuilt checkout: 14% fewer abandoned carts after the error handling was rewritten to say what was actually wrong.
    • Rebuilt the internal editor used by 400 staff so every action is reachable in three keystrokes without a mouse.
    • Wrote the component documentation still used for onboarding.
  3. 2019 — 2021

    Frontend developer

    Lumen & Co · Boston

    • Editorial templates for a newsroom; page weight from 1.9 MB to 240 KB, halving mobile bounce.
    • Introduced a performance budget enforced in CI, which survived two redesigns.
  4. 2018 — 2019

    Web developer

    • Case-study engine plus a dozen client sites.

    Junior developer
