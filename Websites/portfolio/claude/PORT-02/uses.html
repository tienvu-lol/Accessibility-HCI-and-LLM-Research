Uses

The setup, kept honest: everything here was used this month, not merely installed.

Editor and terminal

Editor
A plain editor with four extensions. One of them is my own theme, which is how its contrast bugs get found.
Theme
Umbra, dark variant, at 14px with a 1.6 line height.
Terminal
zsh, a short config, and seven aliases I have had for a decade.
Local server
The one-line Python static server, still undefeated.

Testing and auditing

Automated
axe-core in review on every component, plus a Playwright suite that walks the keyboard path.
Screen reader
The operating system's own, weekly, not at the end of a project.
Zoom
A 400% pass on every new screen; it catches more layout bugs than any breakpoint test.
Contrast
My own small tool: it takes a pair of colours and refuses to be charmed.

Hardware

Keyboard
A 60% mechanical board I have rebuilt twice.
Display
One 27-inch panel at 100% scaling. Two screens made me worse at finishing things.
Phone
A deliberately mid-range Android on a throttled plan, for testing.
Old laptop
A 2016 machine kept alive purely to see what the site feels like on it.

Writing and thinking

Notes
One plain text file per project, appended daily, never reorganised.
Diagrams
Paper first, SVG second, never a diagramming app.
Reading
Specifications, mostly. The WCAG understanding documents repay every hour.
