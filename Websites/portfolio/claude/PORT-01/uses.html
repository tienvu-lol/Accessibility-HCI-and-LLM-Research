Uses

The toolkit, kept honest. If something is on this list it is because I used it this month, not because I meant to.

Desk and hardware
KeyboardA 42-key split board I built in 2024, plus the Keyboard Garden prototype when I want the leaves.
PointerA trackball, because fifteen years of mouse took a toll on one wrist.
DisplayA single 27-inch panel at 100% scaling. Two screens made me worse at finishing things.
PlotterAn AxiDraw-compatible pen plotter, a drawer of fineliners, and a rule about replacing pens every 30 plots.
PrinterA 2014 mono laser that will outlive me.

Editor and terminal
EditorA plain text editor with three extensions: a linter, a git gutter, and nothing else.
FontA 14px monospace at a 1.55 line height, which is wider than most people like.
Shellzsh, a 20-line config, and seven aliases I have used for a decade.
Local serverThe one-line Python static server. It has never let me down.
DiffingOn paper, for anything over 200 lines. It sounds affected and it works.

Software
BrowsersAll of them, plus an old laptop that only runs an old one, which catches more than any test suite.
Screen readerThe one built into the operating system, used weekly rather than at the end.
DesignWhatever the client uses. I read design files; I do not fight about which.
NotesOne plain text file per project, appended to daily, never reorganised.
AuditAn automated accessibility checker in review, and a manual keyboard pass before anything ships.

Type and colour
Body typeA system serif. It is free, it is already on the device, and it reads well at 17px.
Interface typeThe system sans stack, for the same reasons.
Stencil face61 glyphs I cut myself for the plotter. Pen travel is the only design constraint that matters.
PaletteWarm paper, one clay accent, and a blue reserved exclusively for focus indicators.
