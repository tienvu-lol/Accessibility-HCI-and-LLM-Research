Colophon

How this site is made, in the spirit of showing your workings.

The stack

Everything this site runs on
MarkupHand-written HTML5. Twenty-three pages, each complete on its own.
StylesOne stylesheet, with design tokens at the top and a dark palette under prefers-color-scheme.
ScriptOne file of vanilla JavaScript: site data first, then behaviour in a single closure.
ComponentsBootstrap 5.3.3 for the grid, dropdown, offcanvas, collapse and modal, stored locally.
jQuery3.7.1, stored locally and loaded on every page for tooling. This site’s own code never calls it.
ImagesLabelled SVG placeholders, drawn by the generator, no raster files at all.
TypeSystem stacks: a serif for reading, a sans for interface, a monospace for data. Nothing downloaded.
Build stepNone. The file I edit is the file the browser gets.
HostingA folder. Opens over file:// with no server.

Annotation

Every layout region carries a data-section attribute and every repeated or interactive component carries data-component, so any part of the page can be addressed by a stable selector — for example [data-component="availability-card"]. The full list is in component-inventory.json beside the pages.

Things that are deliberately missing

  • Analytics, cookies and third-party scripts of any kind.
  • A content management system. The content is in the files.
  • A theme toggle: this site follows the operating system setting only, which is a deliberate difference from its sibling replicas.

Credits

Bootstrap and jQuery are both MIT licensed; their licence files sit beside them in assets/vendor/. Everything else here was written for this replica.
