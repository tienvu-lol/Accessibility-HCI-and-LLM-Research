Cheatsheets and Snippets - Markdown Powered Gatsby Mini Site

Category: Web Stuff

Technologies: Gatsby, Markdown, React

Overview

This project is a static site generator built with Gatsby that serves as a centralized repository for developer cheatsheets and code snippets. It leverages Markdown files for content management, allowing for easy updates and version control.

Features

  • Markdown-based content structure
  • Fast static site generation
  • Searchable index of snippets
  • Responsive design for mobile and desktop
  • Easy contribution workflow via GitHub

Structure

Content is organized by language and topic. Each cheatsheet is a Markdown file with YAML frontmatter for metadata such as tags, language, and difficulty level.

Getting Started

Clone the repository and install dependencies:

git clone https://github.com/atlas-digital/cheatsheets.git
cd cheatsheets
npm install
