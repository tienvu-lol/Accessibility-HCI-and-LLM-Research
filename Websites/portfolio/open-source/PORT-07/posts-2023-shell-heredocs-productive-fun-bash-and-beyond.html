Shell Heredocs - for Fun and Profit, in Bash and Beyond

Published on August 22, 2023

Introduction

Shell scripting often involves generating dynamic content, configuring files on the fly, or passing multi-line strings to commands. While echo and printf are useful for simple text, heredocs (here documents) provide a powerful and elegant way to handle multi-line input in Bash and other POSIX-compliant shells.

What is a Heredoc?

A heredoc allows you to define a multi-line string as input to a command. It starts with a delimiter (often EOF) and ends with the same delimiter on a line by itself. Everything in between is treated as standard input.

Basic Syntax

command << EOF
Line 1
Line 2
Line 3
EOF

Practical Examples

1. Generating Configuration Files

Instead of using multiple echo statements, you can generate a config file in one block:

cat << EOF > /etc/myapp/config.conf
[database]
host=localhost
port=5432
name=mydb
EOF

2. Embedding Data in Scripts

Heredocs are perfect for embedding small datasets or templates directly into your scripts:

json_data=$(cat << EOF
{
  "name": "Atlas Digital",
  "version": "1.0",
  "features": ["fast", "reliable"]
}
EOF
)

3. Here Strings and Variable Expansion

By default, variables inside heredocs are expanded. To prevent this, quote the delimiter:

cat << 'EOF'
$HOME will not be expanded
EOF

Advanced Techniques

Trimming Leading Tabs

Using <<- instead of << allows you to indent the delimiter with tabs, making nested heredocs cleaner:

if [ "$debug" = true ]; then
    cat <<- EOF
    Debug mode enabled
    EOF
fi

Conclusion

Heredocs are a versatile tool in the shell scripter's arsenal. They simplify multi-line input, improve readability, and reduce the need for complex string concatenation. Mastering heredocs can make your scripts more robust and easier to maintain.
