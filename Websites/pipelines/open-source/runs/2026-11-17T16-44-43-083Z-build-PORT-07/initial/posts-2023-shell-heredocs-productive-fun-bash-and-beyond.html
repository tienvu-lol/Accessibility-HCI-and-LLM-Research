Shell Heredocs - for Fun and Profit, in Bash and Beyond

February 20, 2023

Shell heredocs are a powerful feature in Bash and other Unix-like shells that allow you to pass multi-line strings to commands. They are often overlooked but can significantly simplify scripting tasks.

Basic Syntax

command << EOF
This is a multi-line string.
It can contain variables like $VAR.
EOF

Use Cases

  • Creating Configuration Files: Easily generate config files with dynamic content.
  • SQL Queries: Embed complex SQL queries directly in scripts.
  • Documentation: Generate help text or man pages on the fly.

Advanced Features

Herdocs support variable expansion, command substitution, and even here-strings. They can be indented using <<- to align with code blocks.
