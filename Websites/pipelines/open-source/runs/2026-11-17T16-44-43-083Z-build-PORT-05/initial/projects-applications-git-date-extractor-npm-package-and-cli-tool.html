Git-Date-Extractor NPM Package and CLI Tool

A powerful NPM package and command-line interface (CLI) tool designed to extract date information from Git commits. This tool simplifies the process of analyzing commit history and extracting specific date-related data for further processing or reporting.

Features

  • Extract commit dates in various formats.
  • Filter commits by date range.
  • Export data to CSV or JSON.
  • Easy-to-use CLI interface.

Installation

npm install git-date-extractor

Usage

git-date-extractor --repo /path/to/repo --format json
