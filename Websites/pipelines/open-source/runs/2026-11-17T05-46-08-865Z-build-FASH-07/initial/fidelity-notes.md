## Deviations and Limitations
- **No Real Images**: All images are SVG placeholders
- **No Real Data**: All content is fictional
- **No Real Transactions**: Shopping and newsletter interactions are simulated
- **No Real-Time Updates**: All data is static
- **No External Dependencies**: No CDNs, fonts, or third-party widgets
- **No Server-Side Processing**: All interactions are client-side simulations
- **No Accessibility Audit**: WCAG 2.2 AA is a baseline, not a claim of compliance
- **No Cross-Browser Testing**: Built for Chromium-based browsers primarily
- **No Screen Reader Testing**: Not tested with NVDA, VoiceOver, or JAWS
- **No Zoom Testing**: Not tested at 200% or 400% zoom
- **No Manual Keyboard Walkthroughs**: Not tested with keyboard-only navigation
- **No Performance Testing**: Not tested for load times or resource usage
- **No Security Testing**: Not tested for vulnerabilities
- **No Functionality Testing**: Not tested for real-world usage scenarios
