Cheatsheets and Snippets - Markdown Powered Gatsby Mini Site

A lightweight, static site generator built with Gatsby that allows developers to create and manage code snippets and cheatsheets using Markdown. This project focuses on simplicity, speed, and ease of use for technical writers and developers.

Features

  • Markdown-based content management.
  • Fast build times with Gatsby.
  • Responsive design for all devices.
  • Easy customization via configuration files.

Installation

npm install gatsby-cheatsheets

Usage

gatsby new my-cheatsheets https://github.com/alexmorgan/gatsby-cheatsheets-starter
