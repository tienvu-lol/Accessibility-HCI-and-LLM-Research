# Community College Website
This is a website for a community college, providing information on programs, admissions, and student life.
## Features
* Program and course information
* Admissions and application process
* Student life and services
* Virtual lobby for questions and support
## Requirements
* Modern web browser
* Internet connection
## Usage
1. Open the website in a web browser
2. Navigate to the desired page using the menu
3. Follow the instructions on each page
