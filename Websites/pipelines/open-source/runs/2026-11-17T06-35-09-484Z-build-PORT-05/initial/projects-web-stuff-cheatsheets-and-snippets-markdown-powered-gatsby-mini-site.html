Cheatsheets Mini-Site

Site Screenshot

Overview

This project is a lightweight, static site built with Gatsby that serves as a centralized repository for developer cheatsheets. It uses Markdown files as the source of truth, allowing for easy updates and version control. The site is optimized for performance and accessibility.

Technologies Used

  • Gatsby (React-based static site generator)
  • Markdown / MDX for content
  • Styled Components for styling
  • Netlify for hosting and CI/CD

Key Features

  • Fast page loads due to static generation
  • Easy content updates via Markdown
  • Search functionality for quick access to cheatsheets
  • Responsive design for mobile and desktop
