# Fidelity and limitations
Replicated: utility scheduling/portal links, primary specialty/provider/location/visit navigation, site search affordance; campaign → portal → care areas → family story home sequence; Heart Center local sidebar, overview/team/program/location/resource sections; provider directory shell and individual profile; location directory/main campus; visit-stage resources and financial matters; family/institution-style footer grouping.

Approximated: cyan/green family-focused visual hierarchy, spacious campaign artwork, header geometry, responsive menu, cards and profile presentation. All four SVGs are original geometric illustrations. No source screenshots were available; no pixel fidelity is claimed. Provider body details and rendered directory results were not verified in source evidence.

Simulated: all directory samples, filters, stories, portal dialog, billing statements and appointment choices. Doctor search affordance was observed; facets/results effects untested. Location filters, mobile disclosure and accordion runtime inferred. Family narrative is explicitly illustrative, not a testimonial. Fictional addresses cannot guide travel.

Intentionally added: protocol 404, local-only search results index, preset-only appointment practice form with no free text because source request fields were absent in captured HTML, and safe sample statement selector. These support the authorized research interaction scope; they are not observations of source form fields or payment behavior.

Omitted: real trademarks, copyrighted assets/copy, real clinicians and reviews, research/giving/career subsites, medical guidance, triage, real appointment endpoints, health records, account sign-in, real insurance acceptance or financial eligibility, external maps/social/transaction links. No speculative extra pages.

Unverified: source rendered geometry, dynamic filter behavior, appointment validation and mobile interactions; local browser rendering, axe, screen-reader, keyboard focus, dialog focus trapping, text zoom and responsive reflow until a browser can launch. Native controls and visible focus styles target accessibility but do not prove conformance.
