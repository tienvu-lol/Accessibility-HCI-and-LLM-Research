# Fidelity Notes
This website replica is designed to demonstrate a basic news website structure and functionality.
## Limitations
* The website does not include real-time updates or live news feeds.
* The website does not include user authentication or personalized content.
* The website does not include e-commerce functionality or payment processing.
## Assumptions
* The website assumes a modern web browser and internet connection.
* The website assumes a basic understanding of news website structure and functionality.
