Accessibility statement

This site is a fictional research replica. This statement describes the work actually done on it. It makes no claim of conformance to WCAG or any other standard.

What was designed in

  • Skip link, landmarks, one main heading per page and real table markup with captions and header cells.
  • Keyboard use for menus, tabs, settings, dialogs and the radar controls; Escape closes menus and the dialog.
  • Labeled form fields, an error summary that receives focus, and inline error messages.
  • Light, dark and system appearance, compact and comfortable density, and reduced-motion support. The radar loop never starts on its own.
  • Scrolling table areas are keyboard focusable and named.
  • Maps have a table alternative listing the same values.

What was checked

Automated checks (axe-core in a headless browser) and scripted keyboard flows were run at two widths. No testing with assistive technology users or screen readers was done.

Known limitations

  • Sample illustrations (radar, maps, tracks) are drawn images with text equivalents of limited detail.
  • Contrast in dark mode was spot-checked, not fully audited.
  • Pages that build tables with JavaScript show a notice if scripting is off.

This fictional site has no support desk. Report issues to the research team that supplied it.
