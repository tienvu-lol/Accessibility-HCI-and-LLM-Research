      Accessibility Statement

      Our approach

      This site aims for WCAG 2.2 Level AA as an implementation target. That is a goal, not a claim of conformance: no full audit has been done.

      What has been checked

      Automated axe-core scans and a scripted interaction check were run. Screen readers, 200% zoom and a full manual keyboard review were not tested.

      Known limitations

      • Menus, forms and data tables need JavaScript.
      • The radar viewer is a placeholder image with a decorative overlay.

      Feedback

      Use the demo contact form. It does not send messages.
