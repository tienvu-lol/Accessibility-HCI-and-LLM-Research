## Run locally

Open `index.html` in a browser (works from `file://`). There is no build step, server, network request, or external dependency. Product data is inline in `js/main.js`; the cart is saved in `localStorage` (falls back to memory if storage is blocked) and the promo code in `sessionStorage`.

## Simulation notes

- No orders, payments, accounts, emails, tracking, gift card balances or returns exist. Every such flow validates input and then shows a labeled demo message.
- Search and filtering run over the inline `PRODUCTS` array in `js/main.js`.
- The promo bar, "Free shipping over $99", the shipping rates, tax rate (6%) and store list are invented and are not live operational data.
- The layout pages were authored with a one-off scratch script (not included) to keep the repeated header and footer consistent; the delivered files are plain static HTML, CSS and JS.

## Known limitations

- The reference's dropdown link text, sort option labels and hover behaviour were not captured; they are invented or approximated (see `fidelity-notes.md`).
- The nav dropdown opens on click only, not on hover.
- The product page and listing need JavaScript; without it they show a short message.
- "Trips & Schools" from the reference nav is omitted; "New", "Home Goods", "Packs & Bags" and "Sale" are links to the local results page.
- No pagination, wishlist, reviews list, store map or real images (SVG placeholders).
