This is a structural, reference-inspired replica for an accessibility/usability research dataset. It is **not** a pixel copy, makes no claim of WCAG conformance, and contains no real products, prices, policies or transactions. Every page carries demo labelling where money or accounts would be involved.

## Run it

Open `index.html` in a browser (double-click or `file://`). No server, build step, network or install is needed. All data is inline in `js/main.js`. The bag is kept in `localStorage` (key `softbloom-cart-v1`); the last demo order in `sessionStorage`. If storage is blocked, an in-memory fallback is used (the bag then resets on page change).

## Simulation notes

Nothing is transmitted. Checkout accepts the Luhn-valid test card 4242 4242 4242 4242 and only stores a summary (no card data) in `sessionStorage` for the confirmation page. Sign-in, reset, newsletter and contact forms validate and then show a "Demo only" status. The region select only stores a label; prices remain USD. The cookie button opens an informational demo dialog. The pages were produced with a throwaway generator script that is not part of the delivery; the delivered files are plain static HTML/CSS/JS.

### Not tested

- Screen readers (NVDA, JAWS, VoiceOver, TalkBack) of any kind
- Manual keyboard walkthrough by a person (only scripted keyboard assertions)
- 200% / 400% zoom and text-spacing overrides; Firefox and Safari; real mobile devices
- Windows high-contrast / forced-colors mode; contrast beyond axe's automated checks
- Voice control, switch access, cognitive-load or usability testing with people
- Behaviour with JavaScript disabled (product and listing content is JS-rendered; a `noscript` notice is shown)
- Hover-opened menus (the dropdowns are click-to-open)
- The sticky add-to-bag bar was only checked for show/hide on scroll, not for obscuring focus in every layout (`scroll-padding-bottom` is set as a mitigation)

## Known limitations

- Pages are duplicated static HTML (no includes); shop/product/search/checkout content is generated by `js/main.js` from inline data.
- Product images are generic SVG shapes tinted per collection; thumbnails 2 and 3 are generic illustrations.
- Unknown `?collection=` falls back to "Shop all"; unknown `?id=` shows a not-found state.
- Region selection does not change currency or content.
- Ratings, reviews, stores and policies are invented.
- Hero, filter and sort details of the reference were not characterised in the source inventory.
