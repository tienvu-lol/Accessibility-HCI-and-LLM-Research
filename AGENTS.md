# Repository agent entrypoint

This contract applies to the entire repository, including Codex, Claude Code, other coding agents, and delegated workers.

1. Read [agentic/AGENTS.md](agentic/AGENTS.md) before doing any work.
2. Read [agentic/MAIN.md](agentic/MAIN.md) for the user-owned goals and architecture.
3. Read [agentic/JOBS.md](agentic/JOBS.md) and [agentic/COORDINATION.md](agentic/COORDINATION.md); claim a ready job before implementation.
4. **Never edit, delete, rename, relocate, regenerate, or replace `agentic/MAIN.md` unless Tien Vu explicitly authorizes that specific change.** General instructions to implement, fix, continue, plan, or coordinate do not authorize changes to MAIN.md. Do not alter this protection or create a competing master plan to evade it.
5. Report work, blockers, new jobs, evidence, and proposed blueprint changes in JOBS.md. Every implementation job must cite a MAIN.md section.
6. User instructions take precedence. If a user request changes the blueprint, ask only for the missing specific authorization; continue independent work already authorized by MAIN.md.

Use the uppercase filename `AGENTS.md`; do not create a second lowercase `agents.md` contract.
