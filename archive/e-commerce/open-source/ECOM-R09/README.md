# Outdoor Gear Website
This is a website for Outdoor Gear, a company that sells outdoor equipment and apparel.
## Features
* Home page with navigation menu
* Accessibility page with information on website accessibility
* Outlet page with discounted products
* Trade-in page with information on trading in used gear
* Travel page with travel guides and tips
* Events page with upcoming events and workshops
* Expert Advice page with advice from experienced staff
* Blog page with latest news and articles
* Membership page with information on membership benefits
* Stores page with location finder
## Requirements
* Modern web browser
* JavaScript enabled
