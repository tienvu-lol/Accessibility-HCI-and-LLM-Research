## Interaction and Simulation Notes
- **Inline location search:** Implemented as a text input with a button; on submit shows a demo alert (no real geocoding or data fetch).
- **Forecast tabs:** Implemented with ARIA tablist, tab panels, and JavaScript to show/hide sections; keyboard operable.
- **F/C conversion:** Implemented as a toggle button that changes the label (°C/°F); actual conversion is not performed (demo only).
- **Labeled static radar/map:** Inline SVG placeholder with title/description; a “Refresh” button is non‑functional.
- **Alert filters:** Checkbox group; when any filter is checked a demo alert banner appears (simulated).
- **Intentional additions:** 
  - Demo premium banner (non‑functional) appears on all pages.
  - Login form simulates successful login with client‑side validation only.
  - All weather data is static, fictional samples; no live APIs or external services are used.
