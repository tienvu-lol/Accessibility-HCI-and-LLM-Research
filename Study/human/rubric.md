# Rating rubric

For each item you see two page sets, labelled A and B. For each question pick **A**, **B**, or **Tie**. Judge only what you can see and use. Anchors are fixed before scoring and are not revised.

**Tie rule:** choose Tie when you cannot name a concrete difference for that question, or when the difference is too small to matter to a user. Also choose Tie if the question does not apply to either page set. Do not break ties by overall impression.

**Note rule:** the note field is optional. Fill it only when the difference is sharp, in one sentence that says what you saw. Leave it empty otherwise.

## Q1. Visibility of system status
Pick the one that better shows where the user is and what is happening (current page, selected state, progress, confirmation).

## Q2. Match between system and the real world
Pick the one whose wording, labels and ordering sound like the user's own language, not internal jargon.

## Q3. User control and freedom
Pick the one that makes it easier to back out, undo, or leave a state (clear links back, cancel, reset).

## Q4. Consistency and standards
Pick the one that uses the same words, layout and controls for the same things, and follows common web conventions.

## Q5. Error prevention
Pick the one that better stops mistakes before they happen (clear required fields, input hints, sensible input types, confirmation).

## Q6. Recognition rather than recall
Pick the one that keeps options and context visible so the user need not remember them (visible labels, clear navigation, cues).

## Q7. Flexibility and efficiency of use
Pick the one that gives faster routes for repeat use (shortcuts, skip links, sensible tab order, autofill-friendly fields).

## Q8. Aesthetic and minimalist design
Pick the one with less clutter and a clearer focus on what matters, with no loss of needed information.

## Q9. Help users recognize, diagnose, and recover from errors
Pick the one whose problems are easier to notice, understand and fix. If neither shows any, choose Tie.

## Q10. Help and documentation
Pick the one that offers clearer guidance, instructions or support where a user would need it.

## Q11. Image alt text
Pick the one whose alt text better fits each image's purpose. Weak signs: filenames, "image of...", empty text on informative images, more than 15 words. Judge form and fit to context, not whether it matches the picture.

## Q12. Headings and labels
Pick the one whose headings and labels better describe the content or control that follows.

## Q13. Error messages
Pick the one whose messages tell the user what to do, not only that something is wrong. If neither page set can show an error, choose Tie.

## Q14. Content order
Reading top to bottom, pick the one whose order makes more sense.
