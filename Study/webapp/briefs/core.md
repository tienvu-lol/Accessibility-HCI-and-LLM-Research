# Brief: web server core

Repo: your cwd (git worktree, Windows dev, Node 24). FIRST read Study/webapp/API.md completely: it is the authoritative contract (topology, env, security rules, data layout, auth, endpoints, job shapes, snapshot, projection, addendum). DO NOT git add/commit; leave changes uncommitted.
You OWN only: Study/webapp/server.js, Study/webapp/lib/{auth,keys,store,coordinator,state,projection,importer,sse,http,csv}.js, Study/webapp/package.json (no dependencies; scripts test/start), Study/webapp/test/core*.test.js. Others own lib/results.js, lib/rating.js, public/**, worker.js, Dockerfiles, estimate.py: do not create those.

Build a zero-dependency Node 24 CommonJS server (built-ins only: http, crypto, fs, zlib, child_process, path, stream) implementing:
- Auth: APP_PASSWORD, signed HttpOnly SameSite=Strict cookie, constant-time compares, 5 fails/min/IP rate limit; production refuses to start without APP_PASSWORD and WORKER_TOKEN.
- In-memory key store (never persisted/logged/returned; env defaults). Settings/arms/pricing persisted to DATA_DIR/state.json (never keys).
- Static serving of public/ (SPA at /, /login.html, /rate -> public/rate.html) with path-traversal protection and cache headers. STUDY_DIR env defaults to path.join(__dirname,'..').
- Coordinator: cells = Study/sample/sites.csv x conditions x mainstream arms (A1-A4 only; A5/A6 open_source are never queued), per-arm concurrency cap from Study/config/repair-allocation.json (read-only), 900s leases with heartbeat, immediate release without attempt count on infra failure, expiry requeue, 3 counted attempts then failed, retry-failed, pause/resume, budget stop (spent + in-flight estimate >= budget_usd stops handing out jobs). Score jobs auto-queued when a cell finishes (and for baselines). Judge jobs: one per (site,arm) carrying all four conditions' FINAL-iteration files, only when explicitly started.
- Result ingestion: strict path validation (prefix runs/<arm>/<cond>/<site>/, extension allowlist, size caps), atomic writes under DATA_DIR; append to usage.jsonl; metrics/axe_rules.jsonl; metrics/metrics.csv (dedupe-replace; seed from Study/metrics/metrics.csv on first boot); verdicts/*.csv; blinding_key.csv, per the contract.
- /api/import streaming gunzip NDJSON with per-line validation (open_source arms only).
- /api/state snapshot exactly per the contract (matrix, intake with series/rolling5m/tokens-per-min, projection measured vs estimated, workers, warnings: missing key, placeholder pricing, gemini-as-arm rejected, judge neutrality) and SSE /api/events. estimate.json comes from `python estimate.py --study <Study> --out <DATA_DIR>/estimate.json` (spawn lazily if missing; PYTHON env or python3/python; fall back to chars/4 of slice files if absent).
- /api/variant/... serving stored pages with the sandbox CSP (baseline pages from Study/baseline).
- /api/results and /api/export/<name>.csv delegating to optional lib/results.js (`require` inside try/catch for MODULE_NOT_FOUND only; else 501 JSON). Rating via optional lib/rating.js: `require('./lib/rating').create({dataDir,studyDir,secret}) -> {handle(req,res,url,ctx):boolean}` mounted for /api/rate/ and /rate/frame/ (ctx={readBody,json,sendFile}); these paths require the site cookie.
- Cost = tokens x pricing; placeholder pricing in lib/pricing.default.json with verified:false for every model (claude-opus-5-5, claude-sonnet-5-5, generic openai and gemini). Open-source tokens count, cost 0. DEMO=1 serves a synthetic snapshot. MOCK_PROVIDERS=1 puts mock:true in jobs.
Keep files small and readable; no extra features.

Tests (node:test, offline, temp DATA_DIR, ephemeral port): login + rate limit; keys never appear in any response or state.json; arm PUT rejects gemini and A5/A6; claim respects per-arm concurrency, pause and budget; release does not count an attempt; expired lease requeues; 3 failed results => failed; result path traversal rejected (../, absolute, wrong prefix, bad extension, oversize); import accepts only open_source arms; snapshot has every contract field; projection measured vs estimated; SSE emits state; score job queued after a repair result.
Validate: `node --test --test-reporter=tap Study/webapp/test/core*.test.js` green. Report: files, test summary, deviations from the contract (list any), open risks.
