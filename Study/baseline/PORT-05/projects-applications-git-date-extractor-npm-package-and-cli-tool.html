Git-Date-Extractor NPM Package and CLI Tool

Category: Applications

Technologies: Node.js, NPM, Bash

Overview

Git-Date-Extractor is a lightweight command-line interface tool and NPM package designed to simplify the process of extracting commit dates from Git repositories. It parses Git log output and formats dates into various human-readable or machine-parseable formats.

Features

  • Fast parsing of large Git histories
  • Support for multiple output formats (ISO 8601, Unix timestamp, custom strings)
  • Filtering by date range or specific branches
  • Easy integration into CI/CD pipelines

Usage

npm install git-date-extractor
git-date-extractor --repo ./my-project --format iso

Installation

Install globally via NPM:

npm install -g git-date-extractor
