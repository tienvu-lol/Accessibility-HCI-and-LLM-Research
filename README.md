# Accessibility-HCI-and-LLM-Research
Researching how LLM-driven UI repair affects both web accessibility and usability by jointly evaluating WCAG compliance and Nielsen’s usability heuristics across iterative generation and repair loops.

## Contents
- `Literature/`: published papers and the literature review spreadsheet.
- `Papers/`: project proposal, planning report, simulation and reading notes, UI list.
- `files.zip`: WCAG 2.2 reference archive (verify derived text against W3C).
